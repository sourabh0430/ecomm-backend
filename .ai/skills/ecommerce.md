# E-Commerce Domain Skills

## 1. Product Catalog & Search
- Implementing robust data models for products, variants, and categories.
- Syncing MongoDB product data with Elasticsearch for fast, typo-tolerant search and aggregations.

## 2. Order Management & Cart
- Managing complex cart states (pricing, discounts, tax, shipping calculations).
- Checkout workflow state machines (Pending -> Paid -> Processing -> Shipped -> Delivered).

## 3. POS (Point of Sale) Integration
- Offline-first capabilities for POS clients.
- Real-time inventory synchronization between online and physical stores.

## 4. Webhooks & Third Parties
- Handling asynchronous webhooks from payment gateways (Stripe) to update order statuses.
- Generating shipping labels and tracking packages.

## 5. Real-Time Communication
- Implementing WebSockets (Socket.io) for live chat support and instant notifications.
